# Daybreak cloud publisher

Read `guide/CLOUD_WORKFLOW.md` before handling private data or requests. Use this public repository for source and the existing private Supabase workspace for current data. Keep originals, personal profile, source LaTeX, prepared PDFs, backups, lease tokens and secret values outside this public checkout and out of Git. Normal operation needs no private repository checkout or old vault password.

One publisher operates at a time. Persist a verified Working checkpoint before CV preparation and a verified Ready checkpoint before replying. Never reclaim an ambiguous expired Working request automatically. Preserve immutable artifacts, request receipts, job history and current revision CAS. Keep `approvedForSubmission` false and permitted application hosts empty. No employer form, upload, submission, schedule, paid service or identity change is authorized by a CV request.

`DAYBREAK_SUPABASE_WORKER_KEY` is an injected network secret and may appear as a placeholder. Send it only to the configured Supabase project domain. Never print raw secrets, headers, values or lengths, or place them in shell arguments, source, logs or commits. `DAYBREAK_OWNER_ID` identifies the existing enrolled owner; verify it before use.
